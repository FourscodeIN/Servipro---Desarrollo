# ServiPro — Plataforma Web

**ServiPro** es la nueva página web oficial de una asociación dedicada a brindar servicios personalizados en el área de **sistemas y tecnología**.  
La plataforma ofrece un entorno moderno, visual y funcional para presentar los servicios de soporte técnico, reparación y venta de insumos tecnológicos.

---

## Tecnologías utilizadas
- **HTML5** — estructura semántica moderna.
- **CSS3** — estilos personalizados y responsive design.
- **JavaScript** — interactividad en los módulos y secciones dinámicas.
- **Bootstrap** — base de diseño adaptable.
- **PHP** — seguridad y redirección.

---

## Características principales

### Muestra de marca
- Presenta con imágenes y descripciones los servicios que ofrece la asociación.
- Incluye una **sección de presentación profesional** del equipo.

### Módulos interactivos
- **Módulo de licencias originales.**
- **Módulos individuales para cada impresora/fotocopiadora.**
- **Módulos para repuestos e insumos técnicos.**

### Contenido multimedia
- Video de presentación institucional.  
- Video de servicio técnico para **fotocopiadoras**.  
- Video de servicio técnico para **computadores**.  

### Enlaces de contacto
- Redirección directa a **redes sociales verificadas**.  
- Enlace a **correo y WhatsApp corporativo** para atención personalizada.  

---

## Navegación general
La página está estructurada para ofrecer una experiencia clara y fluida:
1. **Inicio** — Presentación general de la marca.  
2. **Servicios** — Detalle de los módulos técnicos.  
3. **Galería** — Muestra visual de trabajos y equipo.  
4. **Contacto** — Enlaces directos de comunicación.
